# CHANGELOG

This changelog follows the [Keep a Changelog](https://keepachangelog.com/zh-TW/1.1.0/) format to track version updates.

## [1.1.2] - 2026-10-21

### Added

- 新增 23 個上游詞條，涵蓋 Figma Skills、AI 聊天、字型上傳、檔案附件與存取權限。

### Changed

- 以台灣慣用語校正新增詞條，包括「本機字型」、「共用聊天」、「授權條款」與「隱藏式字幕」。
- 統一連接線、說明文件與未儲存文件提示的繁體中文用語，並改善數據傳輸費用等文字表達。

### Fixed

- 將 `Connectors`、`Bent connector`、`Curved connector` 等詞條中的錯誤「連線線」用語修正為「連接器」或「連接線」，並統一相關 AI Agent 用語。

## [1.1.1] - 2026-09-26

### Added

- 新增 127 個翻譯鍵，補上投影片、資料夾、兩步驗證、匯出及相對時間等繁體中文翻譯。

### Changed

- 更新擴充功能圖示（16、48、128 px），並新增 32 px 圖示及對應的 manifest 設定。
- 以動態模式取代 167 筆重複的固定數字詞條，保留一筆尚無對應模式的舊詞條。
- 動態模式優先匹配較具體的字串，避免較短的模式造成部分誤譯。

## [1.1.0] - 2026-08-28

### Added

- 新增 `{@}` 動態模式匹配與 `{1}`、`{2}`、`{3}` 編號回填，支援翻譯動態數量、名稱、方案和日期等內容。
- 新增 553 筆繁體中文詞條，詞庫現有 4,382 個不重複 key。
- 新增 `aria-label`、`data-placeholder`、`data-tooltip` 與 `<i18n-text>` 翻譯支援。

### Changed

- 將翻譯流程更新為「精確匹配 → 動態模式匹配 → 捕獲值翻譯 → 編號回填」。
- 將純文字匹配邏輯拆分為可測試的翻譯引擎，並加入動態模式、語序調整與特殊字元等測試。
- 更新台灣用語，包括「存取權限」、「範本」、「本機字型」、「席次」、「小工具」與「電子郵件」。

### Fixed

- 避免翻譯使用者正在編輯的內容、變數名稱和程式碼編輯器文字。
- 避免翻譯器再次處理自己剛寫回的文字或屬性，減少 MutationObserver 自我觸發。

## [1.0.0] - 2026-06-12

### Changed

- 將 `MutationObserver` 更新排入 frame 批次處理，減少 Figma 動態頁面上的重複 DOM 掃描。
- 在掃描前去除待翻譯根節點中的重複巢狀項目，避免重複處理同一段 DOM。
- 集中管理可翻譯屬性，統一處理 `data-label` 與 `placeholder`。

### Fixed

- 移除一筆查找時永遠不會被使用到的重複 `Open in...` 翻譯項目。
